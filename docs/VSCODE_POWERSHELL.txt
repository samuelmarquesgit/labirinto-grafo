Se quiser usar CMD.exe em vez de PowerShell (alternativa):

1. Abra VS Code
2. Ctrl + , (abrir settings)
3. Procure por: "terminal.integrated.shell.windows"
4. Mude para:
   C:\Windows\System32\cmd.exe

OU deixe PowerShell (recomendado, agora que temos scripts .ps1)


🔍 SOLUÇÃO DE PROBLEMAS
════════════════════════════════════════════════════════════════════════════

P: "Erro: scripts não são reconhecidos como comando"
R: Use o caminho completo:
   PS > .\scripts\test-compile.ps1  (com .\scripts\ antes)

P: "Erro ao executar script PowerShell"
R: Pode ser problema de execution policy. Execute:
   PS > Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   PS > .\scripts\test-compile.ps1

P: "gcc not found"
R: Adicione MinGW ao PATH do Windows e reinicie VS Code

P: "git not found"
R: Instale Git for Windows
   https://git-scm.com/download/win

P: "gh command not found" (para PR)
R: Instale GitHub CLI:
   https://github.com/cli/cli/releases
   Depois faça login: gh auth login

🎯 ATALHOS VS CODE (OPCIONAL)
════════════════════════════════════════════════════════════════════════════

Você pode criar tarefas no VS Code para executar scripts com Ctrl+Shift+B

Arquivo: .vscode/tasks.json

{
  "version": "2.0.0",
  "tasks": [
    {
      "label": "Teste Compilação",
      "command": "${workspaceFolder}/scripts/test-compile.ps1",
      "type": "shell",
      "problemMatcher": [],
      "group": {
        "kind": "build",
        "isDefault": true
      }
    },
    {
      "label": "Compilar (build.bat)",
      "command": "cmd.exe",
      "args": ["/c", "build.bat"],
      "type": "shell",
      "problemMatcher": [],
      "group": "build"
    }
  ]
}
